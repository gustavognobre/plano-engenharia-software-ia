# Regras para a trilha de engenharia de software com IA

- Use este repositório GitHub como fonte oficial da trilha. Toda criação, reestruturação ou atualização dos módulos deve ser registrada aqui em commits.
- Mantenha um documento Word por módulo em `roteiros/`. Explique cada tópico de forma didática e coloque a indicação de vídeo junto do roteiro de leitura correspondente, para permitir o estudo sem assistir.
- Atualize o `index.html` na mesma mudança para que o leitor possa navegar pelos módulos sem abrir pastas.
- Verifique a correspondência entre os roteiros e o HTML antes de concluir a atualização.
