# Flashcards — MCP: protocolo e integrações

Cubra a resposta; revise em 1, 3, 7 e 14 dias.

| Frente | Verso |
|---|---|
| MCP substitui a API? | Não; padroniza como o cliente descobre e usa capacidades expostas por servidores. |
| O que são tools? | Ações invocáveis pelo cliente/modelo com contratos de entrada. |
| O que são resources? | Dados que uma aplicação cliente pode carregar. |
| O que são prompts? | Modelos de interação reutilizáveis. |
| Qual risco de servidor desconhecido? | Acesso indevido ou exposição de dados e execução não pretendida. |
| Por que schema de argumentos? | Para validar chamadas e documentar a interface. |
