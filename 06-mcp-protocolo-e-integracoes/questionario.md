# Questionário — MCP: protocolo e integrações

Responda sem consultar o gabarito. Cada etapa tem duas questões; conclua a etapa após explicar ambas. Critério do módulo: 5 de 6 acertos, prática pronta e correção dos erros.

1. MCP substitui a API?

2. O que são tools?


## Após a etapa 2

3. O que são resources?

4. O que são prompts?


## Após a etapa 3

5. Qual risco de servidor desconhecido?

6. Por que schema de argumentos?


<details><summary>Gabarito comentado — abra depois de responder</summary>

1. **MCP substitui a API?** Não; padroniza como o cliente descobre e usa capacidades expostas por servidores.

2. **O que são tools?** Ações invocáveis pelo cliente/modelo com contratos de entrada.

3. **O que são resources?** Dados que uma aplicação cliente pode carregar.

4. **O que são prompts?** Modelos de interação reutilizáveis.

5. **Qual risco de servidor desconhecido?** Acesso indevido ou exposição de dados e execução não pretendida.

6. **Por que schema de argumentos?** Para validar chamadas e documentar a interface.
