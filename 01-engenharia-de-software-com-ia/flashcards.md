# Flashcards — Engenharia de software com IA

Cubra a resposta; revise em 1, 3, 7 e 14 dias.

| Frente | Verso |
|---|---|
| O que distingue critério de aceite de uma ideia? | Critério é verificável com cenário e resultado esperado. |
| Por que dividir prompts por tarefa? | Facilita revisão e localização de regressões. |
| O que revisar antes de aceitar código gerado? | Comportamento, segurança, testes, dependências e diff. |
| Quem decide o escopo? | A pessoa responsável pelo produto. |
| Por que usar Git em prototipagem rápida? | Para manter histórico e poder revisar e reverter mudanças. |
| Que artefato descreve a experiência de um usuário? | Uma jornada com passos e resultados esperados. |
