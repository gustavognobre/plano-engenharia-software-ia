# Flashcards — LangGraph: estado e orquestração

Cubra a resposta; revise em 1, 3, 7 e 14 dias.

| Frente | Verso |
|---|---|
| O que é estado no grafo? | Dados compartilhados atualizados pelos nós da execução. |
| Para que serve aresta condicional? | Escolher o próximo nó segundo uma condição explícita. |
| O que o checkpoint guarda? | Estado para retomar execução em uma thread. |
| Por que idempotência? | Para evitar duplicar efeitos quando uma etapa é repetida. |
| Onde colocar revisão humana? | Antes de ações com impacto ou baixa confiança. |
| Quando LangGraph é útil? | Quando há rotas, estado, pausas ou retomadas além de uma cadeia simples. |
