# Flashcards — Avaliação, segurança e observabilidade

Cubra a resposta; revise em 1, 3, 7 e 14 dias.

| Frente | Verso |
|---|---|
| Por que conjunto fixo de avaliação? | Permite comparar versões no mesmo cenário. |
| O que é prompt injection? | Instrução hostil inserida em dados menos confiáveis. |
| Qual métrica valida citação? | Se o trecho citado sustenta diretamente a afirmação. |
| Por que medir custo por tarefa? | Para projetar viabilidade e detectar desvios. |
| Como evitar vazamento entre usuários no RAG? | Filtrar acesso antes da recuperação e verificar autorização. |
| O que fazer após uma regressão? | Investigar casos falhos e reverter ou corrigir com evidência. |
