# Flashcards — LLMs, tokens e prompts

Cubra a resposta; revise em 1, 3, 7 e 14 dias.

| Frente | Verso |
|---|---|
| O que é um token? | Unidade de texto usada pelo modelo para entrada e saída. |
| Embeddings substituem a resposta final? | Não; representam dados para comparação e recuperação. |
| Por que saída estruturada? | Facilita validação e consumo por código. |
| Temperatura alta garante criatividade útil? | Não; altera a amostragem e pode elevar variabilidade. |
| Qual é o risco de tratar texto recuperado como instrução? | Prompt injection. |
| Como medir melhoria de prompt? | Comparar os mesmos casos e métricas antes e depois. |
