# Questionário — Hermes Agent e OpenClaw

Responda sem consultar o gabarito. Cada etapa tem duas questões; conclua a etapa após explicar ambas. Critério do módulo: 5 de 6 acertos, prática pronta e correção dos erros.

## Após a etapa 1

1. O que é uma skill neste contexto?

2. O que deve ser limitado no workspace?


## Após a etapa 2

3. Qual diferença entre automação e autonomia?

4. Por que iniciar com dados de teste?


## Após a etapa 3

5. Que pergunta fazer antes de conectar mensagens?

6. Como comparar duas plataformas?


<details><summary>Gabarito comentado — abra depois de responder</summary>

1. **O que é uma skill neste contexto?** Um procedimento reutilizável para orientar a execução.

2. **O que deve ser limitado no workspace?** Arquivos, segredos e recursos que o agente pode acessar.

3. **Qual diferença entre automação e autonomia?** Automação dispara rotina; autonomia envolve decisões dentro de limites.

4. **Por que iniciar com dados de teste?** Para entender efeitos antes de acesso a contas ou dados reais.

5. **Que pergunta fazer antes de conectar mensagens?** Quais dados serão lidos e quais ações podem ser enviadas?

6. **Como comparar duas plataformas?** Pelo mesmo cenário, permissões, custo, logs e resultado.
