# Flashcards — Hermes Agent e OpenClaw

Cubra a resposta; revise em 1, 3, 7 e 14 dias.

| Frente | Verso |
|---|---|
| O que é uma skill neste contexto? | Um procedimento reutilizável para orientar a execução. |
| O que deve ser limitado no workspace? | Arquivos, segredos e recursos que o agente pode acessar. |
| Qual diferença entre automação e autonomia? | Automação dispara rotina; autonomia envolve decisões dentro de limites. |
| Por que iniciar com dados de teste? | Para entender efeitos antes de acesso a contas ou dados reais. |
| Que pergunta fazer antes de conectar mensagens? | Quais dados serão lidos e quais ações podem ser enviadas? |
| Como comparar duas plataformas? | Pelo mesmo cenário, permissões, custo, logs e resultado. |
