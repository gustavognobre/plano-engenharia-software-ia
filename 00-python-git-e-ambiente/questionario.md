<details><summary>Gabarito comentado — abra depois de responder</summary>

1. **Por que usar venv?** Para isolar dependências de cada projeto.

2. **O que um teste de caso vazio verifica?** O comportamento da função quando não há entrada.

3. **Por que não commitar .env?** Porque pode conter credenciais.

4. **O que é uma função pura?** Mesma entrada produz mesma saída sem alterar estado externo.

5. **Como consultar alterações antes de um commit?** Usar git diff e git status.

6. **Qual estrutura associa palavra e contagem?** Um dicionário.
