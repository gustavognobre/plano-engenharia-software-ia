# Flashcards — Python, Git e ambiente

Cubra a resposta; revise em 1, 3, 7 e 14 dias.

| Frente | Verso |
|---|---|
| Por que usar venv? | Para isolar dependências de cada projeto. |
| O que um teste de caso vazio verifica? | O comportamento da função quando não há entrada. |
| Por que não commitar .env? | Porque pode conter credenciais. |
| O que é uma função pura? | Mesma entrada produz mesma saída sem alterar estado externo. |
| Como consultar alterações antes de um commit? | Usar git diff e git status. |
| Qual estrutura associa palavra e contagem? | Um dicionário. |
